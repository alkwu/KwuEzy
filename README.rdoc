== README

This repository contains a Rails application scaffold for property listings.

=== Property Intelligence Dossier Workflow (Advisor Prompt)

When creating a "Property Intelligence Dossier" for a client, make sure the
input always includes a complete property address (street, city, state, ZIP).
Without a valid address, market comps, tax/insurance flags, and HOA/CDD review
cannot be computed reliably.

Suggested response structure:

* <thinking_process>: Assess neighborhood tier, volatility, and likely risk flags.
* <comps>: 3-5 closed sales from the prior 6 months within a 1-mile radius,
  including address, sale price, sqft, and price/sqft.
* <property_analysis>: Structural and cosmetic value drivers and renovation gaps.
* <insider_knowledge>: Three non-listing insights (zoning, school policy,
  development pipeline, turnover trends).
* <financial_audit>: Tax assessment consistency, insurance red flags,
  and HOA/CDD affordability impact on debt-to-income.
* <stakeholder_summaries>: Buyer-friendly and seller-friendly strategic briefs.
* <outreach>: Conversion-oriented client email/text summary.
